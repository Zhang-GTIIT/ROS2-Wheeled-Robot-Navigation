# Ranger Mini V3 Map Data

This directory contains lightweight YAML metadata for the Ranger Mini V3 navigation maps.

The original PGM occupancy maps and `PCD/*.pcd` / `gf/*.pcd` point clouds are intentionally excluded because of their size. Restore the matching files from the private project archive before running the robot, or update the YAML, ICP parameters, and launch scripts to point to your own maps.

Normal Git history is not suitable for large binary maps. Use Git LFS, release storage, or an external object store if these assets need to be distributed.
